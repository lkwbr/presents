# Presents

- The canonical repository is `lkwbr/presents`. Use GitHub Pages for production hosting of both cards and future presents.
- Do not register or publish presents through Sites. Leave the existing Sites publication online as its legacy redirect.
- GitHub Pages publishes `main` from the repository root. Edit here and push to `main` when publication is authorized.
- Cards live in `ben-bday-2025/` and `mom-bday-2026/`, served under `https://lkwbr.com/presents/`. Keep asset paths relative so they work under these prefixes.
- The short public aliases and old `/bennyboo/` link are redirect pages in `lkwbr/lkwbr.github.io`. Preserve them when changing routing.
